## 새 배치

| 부품 | 수납 | 크기/수량 |
|---|---|---|
| P01~P08 Body/Lid | 색별24장, 차량1, 기어1 | 100×95×19mm, 8세트 |
| 플레이어 적층 | 2세트씩 포개 4개 위치 | 한 위치38mm |
| Reserve | 스트레스24 + 열24 | 48장 한 벌 |

| Other | 전설10 + 이벤트18 + 트랙8 | 36장 한 벌 |
| Sponsor | 본판35 + 확장7 + 확장7 | 49장 한 벌 |

| PressUpper | 취재진 코너 말2 | WeatherLower 위 탈착 트레이 |
| Accessory | 작은 예비 부품 | 필수 구성품의 수용은 주장하지 않음 |
| 상단 적층 | 양면맵4, 개인판8, 레전드·챔피언십판, 설명서4, 점수패드3 | 60mm 예약 |

플레이어 카드칸60×91mm, 차량칸34×57mm, 기어칸34×32mm입니다. 바닥2mm와 뚜껑 돌출0.8mm를 뺀 높이는14.6mm. 사용자 차량 측정11×23×7mm는 모든 차량칸에 CAD 직육면체로 넣었을 때 간섭이 없었습니다. 기어 치수는 미확인입니다.

상단60mm는 실측 완료값이 아닙니다. 추정 맵50 + 기본 판류/설명서4 이후 확장 판류/설명서와 점수패드3권에 총6mm가 남습니다. 최종 전체 적층이60mm를 넘으면 모듈 높이를 재조정해야 합니다.

아래 플레이어를 꺼내려면 위 플레이어 모듈을 먼저 분리합니다. 기본6인 사용 시 P07/P08은 빈 모듈 또는 예비 보관으로 사용할 수 있습니다. 뚜껑은 위치를 맞추는 돌출 테두리만 있으며 자석/스냅 고정과 세로 보관 유지력은 검증하지 않았습니다.

## 검증

- 출력 부품29개: 형상 유효, 부품 간 체적 간섭 없음.
- 슬리브 카드 직육면체13묶음 간섭 없음(플레이어8,공용1,후원1,기타1,차고2).
- 차량 직육면체8개 간섭 없음.
- STL 닫힘 및 STEP 유효 형상 확인.
- FCStd 재열기 및 슬리브 변수 변경 후 실제 형상 재계산 확인.
- GUI 표시 상태 저장 후 별도 스타일 적용 없이 재열기·이미지 렌더 확인.
- 실제 출력과 구성품 실물 끼움은 미검증.
