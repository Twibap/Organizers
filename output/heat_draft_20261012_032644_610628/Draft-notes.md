# Heat v0.2 구성품 배치

적용 확장팩: Heavy Rain + Tunnel Vision. 다른 조합은 카드 수량 재계산 필요.

| 배치 | 구성 | 수량 |
|---|---|---:|
| P01~P08 하부 | 기본12 + 시작 업그레이드3 + 스트레스3 + 열6 | 24장 × 8벌 |
| P01~P08 상부 | 해당 색 차량 및 기어 말 | 각 1개 |
| C01 | 공용 스트레스24 + 열24 | 48장 |
| C02 | 차고 기본34 + 고급62 + 확장12 + 확장12 | 120장 |
| C04 상단 | 전설10 + 이벤트18 + 트랙8, 합쳐 한 벌 | 36장 |
| C04 하단 | 후원35 + 확장7 + 확장7 | 49장 |
| Rail01 | 기상6 / 노면12 / 취재진 말 받침 | 3칸 |
| Rail02 | 취재진 코너 말2 / 예비 | 2칸 |
| 상부 적층 | 양면맵4, 개인판8, 전설판1, 챔피언십판1, 설명서4, 점수패드3 | 60mm 예약 |

차고는 한 트레이에 60장씩 나란히 놓는다. 120장을 하나의 수직 더미로 놓으면 측정 표본 기준45mm라 38mm 높이에 들어가지 않는다. 넓은 트레이는 내부124.8×92.4mm로 카드 두 더미를 수용한다.

기타36장과 후원49장은 별개의 덱으로 같은 트레이에 적층한다. 합계85장 추정31.875mm, 덮개 돌출 아래 유효깊이33.6mm, 남는 높이1.725mm. 두꺼운 덱박스/밴드는 계산에 포함되지 않았다.

기본판만 사용하면 플레이어6벌, 공용 스트레스19+열12=31장, 차고96장, 기타24장 및 후원35장이다.

기상/노면 토큰 및 취재진 말은 실측 전 예약칸이며 실제 수용 여부는 미검증. 60mm 상부 공간에는 점수패드까지 포함되어야 한다. 4개 맵50mm는 추정이며 기본 판류·설명서4mm 이후 확장분과 점수패드3권 두께가6mm를 넘으면 높이 배분을 바꿔야 한다.

CAD 형상 충돌, STL 닫힘, STEP 형상, FCStd 재열기 및 매개변수 재계산 검증 통과. 실제 출력/구성품 끼움은 미검증.
